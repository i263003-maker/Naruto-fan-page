Lab 12 Technical Stack & Architecture

This web platform was developed to satisfy the Lab multi-page web app standards using a unified color palette and modern front-end layout:

  • HTML5 Structure: Built using semantic tags including <header>, <nav>, <main>, <section>, <table>, and <footer>.
  • CSS3 Design System: Strict 3-color palette featuring Sage Beige canvas (#f5efe0), Deep Black content containers (#0f141d), and Leaf Orange accents (#ff6f00).
  • Responsive Layouts: Flexbox navigation, responsive Grid cards for character profiles, and overflow tables for fight statistics.
  • JavaScript Interactivity: Dynamic scene recommendations and user review form validation.

Vibe Coding Methodology
